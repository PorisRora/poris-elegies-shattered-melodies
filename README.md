# 珀璃丝追忆录：碎镜余音

**Poris Elegies: Shattered Melodies**

简体中文 · [English](README.en.md)

这是一段破碎的故事，亦是一段破碎的旋律。

经历了那么多，你还记得你记忆中的那个她吗？

**0.1 Beta** · **NeoForge 1.21 / 1.21.1 · Forge 1.20.1** · **仅客户端**

[下载 0.1 Beta](https://github.com/PorisRora/poris-elegies-shattered-melodies/releases/tag/v0.1-beta)

## 你会听到什么

- **36 首曲目**，覆盖主菜单、探索、地下、水下、下界与末地等场景。
- **跟随环境选曲**，生存和创造模式都能根据所在地播放音乐。
- **平缓切换**，带有淡入淡出和曲间留白，尽量避免同一首接连重复。
- **自由点歌**，可查看曲目、播放指定歌曲，或换一首适合当前环境的音乐。
- **可选播放频率与音乐共存方式**，按自己的习惯决定音乐多久响起、怎样与其他模组配合。

音量由 Minecraft 的「主音量」和「音乐」滑块控制。

## 安装

根据游戏版本和加载器选择对应文件：

| Minecraft | 加载器 | Java | 文件 |
| --- | --- | --- | --- |
| **1.21** | NeoForge **21.0.143+**（21.0 分支） | 21 | `poris-elegies-shattered-melodies-neoforge-1.21-1.21.1-0.1-beta.jar` |
| **1.21.1** | NeoForge **21.1.1+**（21.1 分支） | 21 | 同上，两个版本共用 NeoForge 包 |
| **1.20.1** | Forge **47.2.0+**（47 分支） | 17 | `poris-elegies-shattered-melodies-forge-1.20.1-0.1-beta.jar` |

1. 安装上表中与游戏版本匹配的加载器和 Java。
2. 将对应的 **一个**音乐包 JAR 放进游戏实例的 `mods` 文件夹，NeoForge 包和 Forge 包不要同时安装。
3. 更新时先移出 `mods` 中的旧版碎镜余音 JAR，再放入新版并完整重启游戏。

多人游戏只需在自己的客户端安装，服务器无需安装。

目前支持上表中的三个 Minecraft 版本；其他 1.21.x / 1.20.x 小版本暂不包含在支持范围内。

## 按自己的习惯设置

打开 **模组 → Poris Elegies: Shattered Melodies（碎镜余音）→ 配置**。

**主菜单音乐**与**游戏内音乐**可以分别开关。关闭后，对应场景恢复原版背景音乐。新曲开始时，右上角会显示曲名小卡片，也可以关闭。

播放频率控制一首自然结束后，到下一首之间的等待：

| 播放频率 | 曲间等待 |
| --- | --- |
| 频繁（默认） | 1–3 分钟 |
| 标准 | 4–8 分钟 |
| 稀疏 | 10–20 分钟 |

## 与其他音乐一起使用

在配置页选择「音乐共存模式」：

| 模式 | 效果 |
| --- | --- |
| **普通（默认）** | 允许其他模组音乐和唱片播放，可能与碎镜余音重叠。 |
| **让位** | 其他音乐可听见时，碎镜余音淡出；对方结束后，再恢复选曲。 |
| **独占** | 屏蔽其他背景音乐与唱片，继续播放碎镜余音。 |
| **白名单** | 只放行名单内的外部音乐，并在其播放时让位。 |

白名单填写声音事件 ID，例如 `minecraft:music_disc.cat`；也可使用 `模组命名空间:*` 放行该命名空间的音乐。默认名单为空，仅在白名单模式下生效。

Forge 版配置页的白名单用英文逗号分隔多个条目；红色表示 ID 无效，修正后才能保存。

共存设置影响背景音乐和唱片，脚步、战斗、天气与音符盒等音效照常播放。使用独立播放器的音乐模组可能不受这些设置影响。

## 想听哪一首

进入世界后，在聊天栏输入指令。支持 Tab 补全，**无需开启作弊**，多人游戏也可使用。

| 指令 | 用途 |
| --- | --- |
| `/poris melodies list` | 查看全部曲目与编号 |
| `/poris melodies play 02c` | 点播编号为 `02c` 的歌曲，可换成其他编号 |
| `/poris melodies here` | 播放适合当前环境的音乐 |
| `/poris melodies next` | 从当前环境的曲目中重新选一首 |
| `/poris melodies stop` | 停止当前歌曲，之后恢复自动选曲 |
| `/poris melodies now` | 查看正在播放的歌曲、进度或等待原因 |

「播放这里的音乐」「下一首」「查看正在播放」也可以在 Minecraft 按键设置中绑定快捷键，默认未绑定。

## 没听到音乐？

先检查主音量、音乐音量，以及配置里的对应场景开关。曲间等待和让位期间保持安静属于正常行为；用 `/poris melodies now` 可以查看当前原因。

如需反馈异常，请附上 Minecraft、加载器（NeoForge / Forge）和音乐包版本，发生时的场景、共存模式，以及游戏日志 `logs/latest.log`。当前为 Beta，欢迎反馈整合包中的实际表现。

## 从源码构建

安装 JDK 21，并在项目根目录运行：

```powershell
.\gradlew.bat build :forge:reobfJar
```

Linux / macOS 使用 `./gradlew build :forge:reobfJar`。Gradle Wrapper 会下载指定版本的 Gradle，构建工具会在需要时获取 Forge 使用的 JDK 17。首次构建需要联网。

NeoForge 成品位于 `build/libs/`，Forge 成品位于 `forge/build/libs/`。仓库包含游戏使用的 36 首 OGG，无需额外音频转换。资产的本地构建和使用范围见 [ASSET_LICENSE.md](ASSET_LICENSE.md)。
